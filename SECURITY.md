# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Если вы обнаружили уязвимость в самом инструменте JARVIS (не в целевых системах, которые он сканирует), пожалуйста:

1. **НЕ** создавайте публичный issue на GitHub
2. Отправьте описание на email: [your.email@example.com]
3. Мы подтвердим получение в течение 48 часов
4. Мы исправим критические уязвимости в течение 7 дней

## Security Best Practices

- Используйте JARVIS только для аудита систем, на которые у вас есть разрешение
- Не храните результаты сканирования в публичных репозиториях
- Регулярно обновляйте инструмент до последней версии
- Проверяйте сигнатуры WAF и шаблоны rules.yaml на актуальность

## Responsible Disclosure

Мы следуем принципам responsible disclosure и благодарны исследователям, которые помогают улучшить безопасность проекта.
